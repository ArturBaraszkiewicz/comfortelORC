GOTOWOŚĆ DO PRACY
Połączenia.
Narzędzia agentów i integracje działające na serwerze.

      

      
Narzędzia na serwerze
Administrator konfiguruje CLI agentów, dostęp SSH do Git oraz konto integracji z Jira na maszynie wirtualnej. Dostępność CLI nie oznacza aktywnego logowania.
Zadania korzystają z kont i limitów skonfigurowanych na serwerze. Tryb „Zmiany w kodzie” pozwala agentowi edytować kopię projektu i wykonywać polecenia na VM. Kopia Git oddziela pliki projektu, ale nie jest sandboxem systemowym.
